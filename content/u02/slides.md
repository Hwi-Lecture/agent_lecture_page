# LLM은 어떻게 답변할까?
질문에 대한 응답을 자료 없이 먼저 살펴봅니다.

---
<!-- layout: two-col -->
## 입력과 응답
### 모델이 받는 것
- 사용자 질문
- 대화의 맥락과 지시
- 제공된 자료가 있다면 그 내용
|||
### 확인할 것
- 그럴듯해도 틀릴 수 있다
- 날짜와 수치는 원문과 대조한다
- 검색 기능 사용 여부를 기록한다

## 실습 · 기준선 기록하기
질문만 복사해 실제 모델에 입력하고 응답을 기록합니다.

- 모델 이름과 검색 기능 사용 여부
- 모델이 답한 내용
- 나중에 원문과 비교할 관찰점
