# 바이브 코딩으로 AI 서비스 맛보기

자연어로 원하는 화면을 설명하고, 만들어진 결과를 실행한 뒤 고쳐 봅니다. 이번에는 정책자료 안내용 질문 화면을 예로 사용합니다.

## 만들고 확인하기

- 질문 입력칸, 답변 영역, 출처 표시를 갖춘 화면을 요청합니다.
- 실행한 화면에서 빠진 요소나 읽기 어려운 문구를 찾습니다.
- 수정할 내용을 구체적으로 적어 다시 요청합니다.

예시 요청: “정책자료 질문을 입력하는 화면을 만들어줘. 질문 칸과 답변 칸, 출처를 표시할 자리를 넣어줘.”

## 실습

슬라이드의 실습을 열어 화면 시안을 살펴보고 제목을 바꿔 보세요. AI 코딩 도구를 쓰는 수업에서는 같은 요구를 자연어로 전달하고 결과를 직접 실행해 확인합니다. 실습 화면에는 아직 모델이 연결되어 있지 않습니다.
