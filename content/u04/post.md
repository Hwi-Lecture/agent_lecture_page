# 간단한 챗봇 만들기

1단원에서 본 화면에 언어 모델을 연결하면 사용자의 입력에 답하는 간단한 챗봇이 됩니다. 화면과 모델 호출은 서로 다른 역할을 합니다.

## 기본 흐름

1. 사용자가 질문을 입력합니다.
2. 애플리케이션이 질문을 모델에 전달합니다.
3. 모델의 응답을 화면에 표시합니다.

## 수업에서 확인하기

강사가 준비한 도구나 시연 환경에서 이 흐름을 확인합니다. 모델 연결 방법과 계정·비용은 사용할 도구를 정한 후 안내합니다. 이 페이지의 다른 실습은 모델이 연결된 챗봇이 아니라 프롬프트를 연습하는 화면입니다.
