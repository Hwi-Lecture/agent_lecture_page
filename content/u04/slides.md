# 간단한 챗봇 만들기
화면과 모델을 연결하는 기본 흐름을 살펴봅니다.

---
<!-- layout: two-col -->
## 질문에서 답변까지
### 사용자 화면
- 질문을 입력한다
- 응답을 읽는다
|||
### 애플리케이션
- 질문을 모델에 전달한다
- 받은 응답을 화면에 표시한다

---
<!-- layout: default -->
## 시연 · 모델 연결하기
강사가 준비한 환경에서 1단원의 화면에 모델을 연결합니다.

- 연결 전: 질문 화면만 있음
- 연결 후: 모델의 응답이 화면에 표시됨
- 계정과 연결 방법은 수업 도구 선정 후 안내
