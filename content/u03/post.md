# 에이전트는 무엇이 다를까?

챗봇은 대화형 화면이고, LLM은 텍스트를 생성하는 모델입니다. 에이전트는 목표를 수행하도록 모델과 도구를 조합해 여러 단계를 선택하거나 실행하는 시스템입니다.

## 흐름 비교

단순한 챗봇은 질문을 모델에 보내고 답을 표시합니다. 자료 검색 도구가 연결된 에이전트는 검색할지 결정하고, 검색 결과를 참고해 답하도록 만들 수 있습니다.

## 활동

“질문 받기 → 자료 검색 → 결과 확인 → 답변” 단계를 순서대로 적어 보세요. 도구를 실제로 연결하는 작업은 이후 단계에서 다룹니다.
