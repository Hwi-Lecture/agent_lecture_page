# 에이전트는 무엇이 다를까?
목표에 따라 도구를 사용하고 단계를 수행합니다.

---
<!-- layout: two-col -->
## 질문에 답하는 두 흐름
### 단순 응답
질문 → 모델 호출 → 답변 표시
|||
### 도구를 활용하는 흐름
질문 → 검색 도구 선택 → 자료 확인 → 답변

도구를 사용하는 방식과 범위는 설계에 따라 달라집니다.

---
<!-- layout: default -->
## 활동 · 단계 배열하기
정책자료에 근거해 답하는 과정을 순서대로 적어 봅니다.

1. 사용자에게 질문을 받는다
2. 관련 자료를 찾는다
3. 찾은 내용을 확인하고 답한다
